#+TITLE: Casos: implementações dos exemplos

Cada caso tem uma pasta, e cada tecnologia uma subpasta:
=casos/<caso>/<tecnologia>/=. Cada subpasta é um projeto completo, com o
próprio =package.json=, e pode ser lida sozinha. O escopo (casos e
tecnologias) está em
[[file:../revisoes/20260925-2313Z_escopo-casos-e-plataformas.md][revisoes/20260925-2313Z_escopo-casos-e-plataformas.md]].

* Pré-requisito: Node.js

  A versão fica em =.tool-versions=, na raiz do repositório, e o [[https://asdf-vm.com][asdf]] a
  instala:

  #+begin_src sh
  asdf plugin add nodejs
  asdf install
  #+end_src

  O Angular 22 exige Node 22.22.3 ou mais novo.

* Instalar e rodar (web)

  Os projetos web são /workspaces/ do npm, todos em TypeScript: um único
  =npm install= na raiz instala todos. O =build= confere os tipos com =tsc=
  antes de empacotar.

  #+begin_src sh
  npm install
  npm run dev -w casos/contador/react
  #+end_src

  Troque o caminho pelo do exemplo desejado. O Vite serve em
  =http://localhost:5173= e o Angular em =http://localhost:4200=.

  | Subpasta         | Tecnologia                                     |
  |------------------+------------------------------------------------|
  | =web-component=  | DOM puro com /custom element/ (classe)          |
  | =jquery=         | jQuery                                         |
  | =react=          | React                                          |
  | =solid=          | Solid (/signals/)                               |
  | =angular-rxjs=   | Angular com RxJS (apoio à escrita; fora do texto) |

  O =cronometro-com-rxjs-5= é anterior a esta organização e não é
  /workspace/: tem instalação própria.

* Capturas de tela

  Cada caso guarda capturas versionadas em =casos/<caso>/capturas/=, uma
  por tecnologia e cena (=react-inicial.png=, =react-erros.png=...). Ao
  criar ou alterar um exemplo, gere-as de novo e inclua no mesmo commit:
  o =git diff= mostra o que mudou na tela.

  #+begin_src sh
  npx playwright install chromium-headless-shell   # só na primeira vez
  npm run capturas                                  # todos
  npm run capturas -- formulario                    # um caso
  npm run capturas -- contador/react                # uma implementação
  npm run capturas -- --conferir                    # só compara, não grava
  #+end_src

  O =--conferir= gera as imagens numa pasta temporária, compara com as
  versionadas e lista as que mudaram, as novas e as que sumiram, saindo com
  erro se houver alguma. Rode antes de commitar uma alteração num exemplo:
  se algo mudou de propósito, regenere; se não, é regressão.

  As cenas de cada caso ficam em =casos/<caso>/cenas.mts= (ações do
  Playwright antes da captura); sem ele, só o estado inicial é capturado.
  O /script/ ([[file:capturar.mts][casos/capturar.mts]]) faz o /build/, serve o resultado, fixa a
  data em 26/09/2026 (para "hoje" não mudar a imagem) e, no fim, avisa se
  a mesma cena saiu diferente entre as tecnologias de um caso, o que indica
  que alguma implementação foge da especificação.

  Agentes de código seguem essas regras pelo [[file:AGENTS.md][casos/AGENTS.md]] (o
  =CLAUDE.md= ao lado é um /symlink/ para ele).

  As imagens dependem das fontes instaladas: geradas noutra máquina, podem
  mudar sem que o código tenha mudado.

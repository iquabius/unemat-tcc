* [[file:../prog.org::O /callback/ é síncrono quando a][prog: O /callback/ é síncrono quando a]], p. 2
- Frase: “O /callback/ é síncrono quando a função que o recebe o chama
  antes de retornar, e assíncrono quando o chama algum tempo depois, ao
  fim da operação que ele espera.”
- Trecho: “A callback passed to a function f can be invoked synchronously
  before f returns, or it can be deferred to execute asynchronously some
  time after f returns.”; “the desired non-blocking operation is scheduled
  as a callback and the main thread continues its synchronous execution.
  When the operation completes, a message is enqueued into a task queue
  along with the provided callback.” (p. 2)

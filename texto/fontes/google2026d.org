* [[file:../cases.org::Na web, Web Component, React e Solid][cases: Na web, Web Component, React e Solid]]
- Frase: “O Lit se constrói sobre o Web Component: seus componentes são
  elementos personalizados do navegador, mas cada alteração de estado chama
  de novo o método que monta a tela (Google, 2026d).”
- Trecho: “Lit components are standard custom elements and inherit the
  custom element lifecycle methods.”; “The reactive update cycle is
  triggered when a reactive property changes or when the requestUpdate()
  method is explicitly called.”; “The component’s render method is called
  to update its internal DOM.”
- Lido em: =acervo/google2026d.html= (página salva em
  2026-10-13; lit.dev/docs/components/lifecycle/).
- Observação: que o par Web Component e Lit mantém o modelo de componente
  e a orquestração é do próprio delineamento (ADR 0013), e não da fonte.
- Conferido: 2026-10-13.

* [[file:../intro.org::As sete interfaces são implementadas na web por cinco tecnologias][intro: As sete interfaces são implementadas na web por cinco tecnologias]] (o ramo do Lit)
- Frase: “Muda o modo como a alteração do estado chega à tela e, com ele, a
  montagem das partes repetidas. A alteração de uma das propriedades
  reativas que o componente declara, ou a chamada de =requestUpdate()=,
  agenda uma atualização, em que o ambiente de execução chama de novo o
  método que monta a tela (Google, 2026d).”
- Trecho: “The reactive update cycle is triggered when a reactive property
  changes or when the requestUpdate() method is explicitly called. Lit
  performs updates asynchronously so property changes are batched”; “The
  component’s render method is called to update its internal DOM.” (seção
  “Reactive update cycle”).
- Lido em: =acervo/google2026d.html= (página salva em 2026-10-13;
  lit.dev/docs/components/lifecycle/).
- Observação: A fonte sustenta o ciclo: a alteração de propriedade agenda a
  atualização e o render() é chamado durante esse ciclo. A mesma classe e a
  mesma orquestração do Web Component são do delineamento (ADR 0013), e não
  da fonte. Em 2026-10-28, a frase mudou na checagem adversarial: a
  alteração de propriedade agenda uma atualização, que pode reunir várias
  alterações. Em 2026-10-30, na segunda passada, entraram “reativas” e o
  segundo gatilho do trecho, o =requestUpdate()=, que a Planilha e o
  Circle Drawer do Lit chamam depois de alterar os dados no lugar; a
  ressalva de que esse é o uso avançado está em google2026e, e a
  montagem das partes repetidas, no ADR 0013 (decisão do autor).
- Conferido: 2026-10-25; de novo em 2026-10-28 e 2026-10-30.
